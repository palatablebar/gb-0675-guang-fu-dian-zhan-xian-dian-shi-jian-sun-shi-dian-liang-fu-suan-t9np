# 功率与限电定义

设备额定功率为kW。遥测kW与MW统一为kW，辐照度为W/m²。样本时刻须带偏移，统一UTC。记录代表自采样时刻起600秒的左值保持区间，超过600秒不外推，缺测保持未定。
每台设备重叠或相邻限电事件先求并集，再按遥测及有效期边界切分半开区间。样例INV-A的10:00–10:20及10:10–10:30合并为30分钟，不能重复积分重叠10分钟。
基线只采用同区域、同采样时刻、同100W/m²辐照档、健康且不处于限电中的参考逆变器；至少2台。对参考功率按各自额定功率归一，取中位数再乘目标额定功率，基线不超过目标额定功率。无合格对照返回NO_REFERENCE及null损失，不填0。
每片段损失=max(基线−实际,0)×秒数/3600。实际高于基线时损失0。计算保留Decimal精度，汇总后统一保留0.0001kWh；未定时长单独展示，不并入已确定损失。
清批INV-A基线100kW、实际60kW、并集30分钟，损失20kWh；INV-B基线50、实际30、20分钟，损失6.6667kWh。总确定损失26.6667kWh。能量核验按实际+非负损失计算可解释基准电量。
同设备同一时刻不同观测全部隔离；同值重复观测保留稳定编号。封存需无隔离和未定片段。此工具供离线复算，不包含生产控制或电网调度。

# 设备身份台账（换型双编号）

逆变器换型后新旧编号各有一段运行记录。裁定为**待证后并**：值班可先登记换型链路，但凭证齐全并通过审计校验前，两个编号保持独立物理身份，限电事件、基线依据与损失各自保留、不汇总、不共用；校验通过后在单个数据库事务内原子切换为同一物理身份。

## 链路状态机

待确认（REGISTER）→ 已确认（CONFIRM）/ 保持原状态（CONFIRM_REJECTED）；已确认或待确认 → 已撤回（WITHDRAWN）；已撤回在凭证补齐后可重新确认（CONFIRM，审计标注“撤回后重新确认”）。不存在中间态：确认失败只追加驳回审计并回滚其余写入，绝不留下半合并。所有状态变更写入只增不改的 `identity_events`，含动作、前后状态、操作人、原因与整链路快照。

## 确认前必须全部通过的审计校验

- DOC_INCOMPLETE：换型工作票、资产台账记录、更换现场照片、交接验收单四类凭证齐全；
- ASSET_GAP / ASSET_MISMATCH：新旧资产编号都存在且一致，否则可能是两台相邻设备；
- NEIGHBOR_RISK：同区域存在其他设备时，必须给出排他性安装位置说明；
- OVERLAP_RUNTIME：两个编号的运行时段不得重叠，同一物理设备同一时刻只能有一个编号运行；
- CODE_BOUND：一个编号同一时刻只能归属一条已确认链路，不同设备不能共用履历。

## 连续视图与重算范围

- 待确认：`traceable=false`，`joined_loss_kwh=null`，页面逐段显示“不可连续追溯”及待确认依据；
- 已确认：`physical_id` 下两段履历拼接，跨编号事件、对照基线依据（`reference_ids`）与损失连续查看，损失为两段之和（换型样例 16.0000+10.6667=26.6667kWh）；
- 撤回：仅重算该链路所属物理身份的 `identity_chains` 视图，其他链路 digest 不变；批次表 `runs` 与原始编号记录在任何台账操作中都只读，不删除、不覆盖、不新增身份。

换型链路编号 `LNK-` 与物理身份编号 `PHY-` 均由新旧编号确定性派生，重复登记/重试幂等返回同一链路。归档包新增 `identity_ledger.json` 封存台账快照。
